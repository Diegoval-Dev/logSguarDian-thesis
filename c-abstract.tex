Technology startups building on Node.js rarely have a dedicated security team. This work presents logSguarDian, an npm library that implements a runtime application self-protection (RASP) middleware for Express and detects SQL injection, cross-site scripting, path traversal, and command injection. A Random Forest, trained on 268,240 of the 383,202 rows of the corpus, decides blocking, and an Isolation Forest, trained only on benign traffic, logs anomalies without blocking.

The extractor takes 0.0273 ms (p95; 5 ms limit). The Random Forest reaches a macro F1 of 0.9776, and the Isolation Forest a recall of 0.9125 with a false positive rate of 0.0546. Coverage exceeds 80\,\% per category in SQL injection, path traversal, and command injection. The 15 ms p95 latency criterion is met under normal and attack load but not under volume load, and the memory and CPU criteria are not met.

The general objective was partially met. With a browser User-Agent, the validated model flagged for blocking 97.1\,\% of benign requests in Juice Shop (\textit{monitor} mode), and an undocumented model blocked 92.5\,\% in dvws-node; the benign corpus is the main weakness. The metrics measure separation within the corpus rather than generalization, because the partitions share near-duplicates and the test set was read three times. It is recommended to publish a version with the evaluated models, expand the benign corpus, and measure per-component cost.
