Technology startups building on Node.js rarely have a dedicated security team. This work presents logSguarDian, an npm library that implements a runtime application self-protection (RASP) middleware for Express and detects SQL injection, cross-site scripting, path traversal, and command injection. The middleware extracts 76 features from each request and evaluates them in \texttt{worker\_threads} with a hybrid model: a Random Forest decides blocking and an Isolation Forest logs anomalies without blocking. The models were trained on 268,240 of the 383,202 rows of the corpus and evaluated on a locked test set and in five applications.

The extractor takes 0.0273 ms per request (p95; 5 ms limit). The Random Forest reaches a macro F1 of 0.9776, and the Isolation Forest a recall of 0.9125 with a false positive rate of 0.0546. Coverage exceeds 80\,\% per category in SQL injection, path traversal, and command injection with the evaluated model. The 15 ms p95 latency criterion is met under normal and attack load but not under volume load, and the memory and CPU criteria are not met.

With a browser User-Agent, the validated model flagged for blocking 97.1\,\% of benign requests in Juice Shop (\textit{monitor} mode), and an undocumented model blocked 92.5\,\% in dvws-node; the benign corpus is the main weakness. The partitions share near-duplicates and the test set was read three times; the metrics measure separation within the corpus.
